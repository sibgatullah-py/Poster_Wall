About PosterWall

PosterWall is a simple social posting platform built with Django.

This project allows users to create accounts, post tweets, upload images, manage their profiles, and interact with their own content in a clean and minimal interface.

It was built to practice real-world backend concepts like authentication, media handling, CRUD operations, and Django’s ORM.

The goal of PosterWall is to demonstrate how a modern Django application is structured using industry best practices.
